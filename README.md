# Progetto: AI Content Curator

## Descrizione
Sviluppa un'applicazione web full-stack che permetta agli utenti di curare e organizzare contenuti generati da AI.

## Funzionalità richieste

### Autenticazione
- Registrazione utente con email e password
- Login/logout
- Protezione delle rotte private

### Gestione dei contenuti
- Creazione di nuovi contenuti tramite prompt AI
- Salvataggio dei contenuti generati
- Organizzazione in categorie o collezioni personalizzate
- Visualizzazione di tutti i contenuti generati dall'utente

### Integrazione AI
- Integrazione con almeno un servizio AI esterno (puoi utilizzare OpenAI, HuggingFace, o qualsiasi altro servizio pubblico)
- Possibilità di modificare/migliorare i contenuti generati attraverso nuovi prompt

### UI/UX
- Interfaccia responsive
- Design pulito e intuitivo
- Feedback visivo per le operazioni di lunga durata

## Requisiti tecnici

### Frontend
- TypeScript obbligatorio
- Framework a scelta (React/Next.js consigliato ma non obbligatorio)
- Gestione dello stato dell'applicazione
- Form validation

### Backend
- TypeScript obbligatorio
- NodeJS 
- API RESTful o GraphQL
- Utilizzo di Drizzle ORM per la gestione del database
- Implementazione di middleware per autenticazione

### Database
- PostgreSQL obbligatorio
- Schema ben progettato con relazioni appropriate

### DevOps
- Repository GitHub con struttura chiara
- README con istruzioni di installazione e utilizzo
- Variabili d'ambiente configurate correttamente

## Bonus (non obbligatori ma apprezzati)
- Test unitari e/o di integrazione
- Docker/Docker Compose per facilitare il setup dell'ambiente
- Implementazione di una funzionalità di cronologia delle versioni per i contenuti generati
- Possibilità di condividere i contenuti con altri utenti
